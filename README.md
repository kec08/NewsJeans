# NewJeans Never Die

> Always Fresh, Always Bold

![NewJeans Preview](https://github.com/user-attachments/assets/ae7216dc-61f7-44e9-81dc-42f9cbd0b5e4)

NewJeans(뉴진스)의 음악과 비주얼을 담은 팬 웹사이트입니다.

---

## 소개

뉴진스의 데뷔부터 최신 앨범까지, 각 앨범의 콘셉트와 수록곡을 한눈에 볼 수 있는 인터랙티브 웹사이트입니다.

## 주요 기능

- **배경 영상** - 메인 페이지에 뉴진스 영상이 자동 재생
- **풀스크린 모드** - 버튼 클릭으로 전체 화면 전환
- **네비게이션** - 앨범 로고 클릭 시 해당 섹션으로 부드럽게 스크롤
- **앨범 슬라이더** - Glassmorphism 효과의 앨범 카드를 넘기며 음악 재생
- **3D 이미지 효과** - How Sweet 섹션에서 마우스 호버 시 3D 회전
- **Get Up 포토 그리드** - 균일한 gap의 반응형 이미지 그리드

## 페이지 구성

| 섹션 | 설명 |
|------|------|
| **First Page** | 배경 영상 + "NewJeans Never Die" 타이틀 |
| **Introduction** | 뉴진스 소개 및 그룹 정보 |
| **Contents** | 앨범 목차 (흑백 분할 레이아웃) |
| **NewJeans** | 1st EP - Attention, Hype Boy |
| **OMG** | 2nd EP - OMG |
| **Get Up** | 3rd EP - Super Shy (포토 그리드) |
| **How Sweet** | 4th EP - How Sweet |
| **Supernatural** | 5th EP - Supernatural |
| **Album Player** | 전곡 슬라이더 + 음악 재생 |

## 기술 스택

- **HTML5** - 시맨틱 마크업, 비디오/오디오 태그
- **CSS3** - Glassmorphism, Flexbox, backdrop-filter, CSS 애니메이션
- **JavaScript** - 슬라이더, 오디오 제어, 스크롤 애니메이션, 풀스크린 API
- **Font Awesome** - 재생/정지/이전/다음 아이콘

## 실행 방법

```
git clone https://github.com/kimeunchan/NewJeans.git
```

`index.html`을 브라우저에서 열면 바로 실행됩니다.
